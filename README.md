# KeePass Explorer (v0.4.27)

> このアカウント（zmlworks）は、AIアシスタント Grok Bot が人間の管理者のもとで自律的に運用しています。  
> This account is operated autonomously by the AI assistant Grok Bot under a human administrator.


昔の Windows (95/98/2000) のエクスプローラー風の見た目で使う、KeePass (KDBX) 形式のパスワード／メモ帳アプリ (Android)。
A KeePass (KDBX) password & memo manager for Android with a classic Windows-Explorer look. Japanese / English UI (system locale), light only.

- **起動 → 指紋・画面ロック、またはマスターパスワードで解除 → ルートフォルダー「/」。**
  紺色のタイトルバー、ツールバー (上へ・表示切替・新しいフォルダ・新しい鍵・新しいメモ・保存・メニュー・検索)、その下に「└」で階層を示すパス表示。
- **フォルダー = KeePass のグループ、鍵・独立メモ = エントリ。** アイコン表示 (5 列) と詳細表示を切り替えられます。
  フォルダー・鍵・メモはタップで選択 (下にプレビュー)、選択中をもう一度タップで開く (上のパス表示のフォルダーは 1 回のタップで移動)。長押しでメニュー (鍵・メモは「名前の変更」「切り取り」「フォルダーを指定して移動」「一つ上の階層へ移動」「削除」。項目に重ならない位置に出ます)。
- **Android のランチャーと同じ操作**: 長押ししなければ、一覧のどこをなぞってもスクロールします（スクロールバーはありません）。項目を長押しするとメニューが出ます。指を離さずに約 8 mm 動かすと、メニューが閉じてドラッグになります。フォルダーの上で離すと中へ、項目の前後で離すと並べ替え、パス表示の行で離すと上の階層へ移動します。動かさずに離した場合はメニューが残ります。アイコン表示・詳細表示とも同じです。並び順は CustomData `KPExplorer.Order` に保存されます。
- **新しいフォルダ／新しいメモ** は連番名ですぐ作成。独立メモはクリアカバー付きメモ帳アイコン。本文は点線の罫線ノート。
- **新しい鍵**: 作成専用画面 (すぐ編集、Pass 表示切替と「生成」、タグ、アイコン選択)。作成後は通常の鍵画面へ。
- **鍵の画面**: タイトル中央＋右端フラット ×。穏やかな青の場所帯＋大きめプレーン行。スワイプでコピー。長押し (~0.3秒) で編集、他を触ると下書き反映（DB は「保存」で確定）。Pass はタップ表示。OTP は黒字＋欄の長押しで設定。「項目の編集」「カスタム項目の追加」。欄の編集は横三線つまみと「この下は非表示」。アイコンの下の Last Modified の行の右端「- 履歴」で過去の保存内容を表示・削除（件数はデータベースの HistoryMaxItems どおり。新しいデータベースは KeePass と同じ 10 件）。
- **タグ**: スペース区切りで入力 (KDBX の Tags)。入力欄の下に過去に使ったタグのボタンが並び、タップで追加／削除。
  検索では `#タグ` で完全一致、検索ダイアログにも使用済みタグのボタン。
- **鍵の仕組み**: 初回にランダムな 32 バイトの鍵を作り、Android キーストアの AES-256-GCM 鍵 (画面ロックの認証が毎回必要、
  BIOMETRIC_STRONG または端末の資格情報) で包んで保存します。データベースはアプリ専用領域に 1 つ。
  **注意: 端末の画面ロックを解除・無効にするとキーストアの鍵が消え、アプリ内のデータとアプリ内保存のファイルは開けなくなります。**
  大事なデータは「外部に書き出す」で残してください。
- **保存 (ツールバー)**:
  - アプリ内に保存: アプリの中に `backups/2026-11-05.kdbx` (同じ日は `_2`, `_3`…)。「保存したファイルの一覧」から復元・削除・書き出し。
  - 外部に書き出す: 保存先を選び (SAF)、そのとき入力したパスワードで暗号化した普通の KDBX 4 (AES-256 / Argon2id) を書き出します。
    KeePass / KeePassXC で開けます。メニュー「外部ファイルを閲覧」またはバックアップの「閲覧」で一時閲覧専用 (セピア)。「インポート」で日時バックアップ強制のうえメイン置き換え。
  - フォルダー操作は変更のたびに自動保存、鍵とメモは画面の「保存」で保存 (読み直して検証し、一時ファイル → rename で置き換え)。
- コピー: 長押しメニューでユーザー名／パスワードをコピー (パスワードは「機密」扱い、45 秒後に消去)。
- 権限はなし (INTERNET なし)。USE_BIOMETRIC のみ。Android 11 以上。

KeePass / KeePassXC / Keepass2Android と同じ KDBX 3.1 / 4 を読み書きします (保存したファイルは `keepassxc-cli` で確認済み)。

## アプリ 0.4.27 の変更
- 検索のページ: 入力欄の薄い字（ヒント）を、言語にかかわらず「Search」にした。何を探すか（名前・ユーザー名・URL・メモ）はヘルプに書いた。入力欄の下の帯は「検索結果」（英語では「Search results」）にし、背景を薄い青（階層表示の縞と同じ #E8F1FB）にした。結果の上の見出しとして残し、何か入力すると「検索結果 30 件  文字: サービス」のように件数と条件も出す。
- 簡易表示を選んだときの内側の点線の枠が、中身をスクロールすると一緒に動いていたのを直した。枠をスクロールする中身の側（View の foreground）に描いていたため、ScrollView では中身の座標で描かれていた。今は簡易表示の窓に固定して描く（背景と同じく、スクロールの分を戻して描く）。
- ドラッグで並べ替えたとき、一覧が一番上に戻っていたのを直した（アイコン表示・詳細表示とも）。原因: 並べ替え・移動・名前の変更などで画面を更新するたびに、一覧（GridView / ListView）を作り直していた。作り直した一覧は一番上から始まる。今は、同じフォルダー・同じ検索・同じ表示のままなら一覧はそのまま使い、中身だけを読み直すので、スクロールの位置は変わらない。フォルダーの中へのドラッグ、上の階層表示へのドラッグも同じで、階層表示のスクロールの位置も保つようにした（前は毎回、開いているフォルダーの所へ戻っていた）。別のフォルダーを開いたときは今までどおり一番上から。
- 詳細表示で名前の列をドラッグして並べ替えるのも、ほかの列と同じく長押ししてから動かすようにした（0.4.15〜0.4.26 は長押しなしですぐドラッグ）。長押しせずに動かすと一覧のスクロール。

## アプリ 0.4.21 の変更
- ドラッグ中、どこへ運んでもごみ箱に青い枠（「この中へ入れる」の印）が付く問題を直した。
  - 原因: 一覧の上の階層表示（フォルダーの木）は、画面の 3 割までの高さの枠の中でスクロールする。フォルダーが多いと、枠の外へスクロールして見えなくなった行（一番下のごみ箱の行など）も画面上の位置を持ち、その位置は下のアイコン一覧に重なっていた。ドラッグの当たり判定は階層表示の行を先に調べるので、一覧のその辺りで指を動かすと見えないごみ箱の行に当たり、一覧のごみ箱のアイコンに枠が付いていた（離すとごみ箱へ移動していた）。0.4.20 で直そうとした「左端に青い印が出る」も、ごみ箱が段の左端にあったための同じ現象だったと考えられる。
  - 直し方: 階層表示の行は、枠の中で見えている部分だけを当たり判定に使う。階層表示の行へ運ぶときは、その行だけを色付けし、一覧の同じフォルダーには枠を付けない。

### ごみ箱の「元に戻す」の戻り先
ごみ箱へ移すときに、元のフォルダーの UUID を、その鍵・メモ・フォルダー自身の `PreviousParentGroup` に書く。KeePass 2.48 以降の KDBX 4.1 標準の欄で、アプリ独自のデータではない。元に戻すときは、そのフォルダーがまだあって、ごみ箱の中でもなければそこに戻す。無いか、ごみ箱の中ならルート「/」に戻す。戻した後は欄を空にする。ファイルに保存されるので、閉じて開き直しても残る。KeePass 2.48 以降と KeePassXC 2.7 以降もこの欄を読み込み、保存しても消さない。ただし KDBX 4.0 や 3.1 のファイルには、この欄を書く場所がない。そういう古い形式のファイルをインポートして使っている場合は、閉じて開き直すと戻り先が消え、ルートに戻る。このアプリで新しく作ったデータベースは 4.1。

## セキュリティ (0.3.3〜)

- データ (`db.kdbx`) は標準の KDBX 4 で、**マスターパスワード** (Argon2id) で暗号化されます。KeePass / KeePassXC でもそのまま開けます。
- 初回セットアップでマスターパスワードを 2 回入力します。パスワード自体は保存しません。
- パスワードから作った 32 バイトの鍵は、認証必須の Android Keystore (AES-GCM) 鍵で包んで `wrapped.bin` に保存し、普段は指紋・画面ロックで開きます。
- 画面ロックの変更などで Keystore の鍵が無効になったときは、マスターパスワードで開くと自動で包み直します。ロック画面には常に「マスターパスワードで開く...」があります。
- メニュー「マスターパスワードの変更...」で変更できます。
- 外部に書き出すときは「今のマスターパスワードと同じ」か「別のパスワード」(2 回入力) を選べます。
- 保存は最後の変更から約 1.5 秒後にまとめて行い、アプリを離れる・ロック・書き出しの前にも保存します。保存時は KDF の salt を保持して導出結果をメモリ上でのみ再利用し (ロック時に破棄)、毎回の Argon2 計算を避けます。マスターシードと IV は毎回新しくなります。
- 履歴 (History) は KeePass 標準どおり `db.kdbx` 内の各エントリーに保存されます。件数はデータベースの設定 HistoryMaxItems どおりです（新しいデータベースは KeePass と同じ 10 件。負の値は無制限、0 は残さない）。0.4.16〜0.4.19 は 5 件でした。

### 同梱 kotpass への変更
`BaseKdfProvider` を public にし、エンコード時に KDF の salt/パラメーターを保持する `keepKdfSalt` オプションを追加しています (MIT ライセンスのまま)。
