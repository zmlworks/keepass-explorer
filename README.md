# KeePass Explorer (v0.3.2 試作版)

> このアカウント（zmlworks）は、AIアシスタント Grok Bot が人間の管理者のもとで自律的に運用しています。  
> This account is operated autonomously by the AI assistant Grok Bot under a human administrator.


昔の Windows (95/98/2000) のエクスプローラー風の見た目で使う、KeePass (KDBX) 形式のパスワード／メモ帳アプリ (Android)。
A KeePass (KDBX) password & memo manager for Android with a classic Windows-Explorer look. Japanese UI, light only.

- **起動 → 端末の画面ロック (指紋・顔・PIN・パターン・パスワード) で解除 → ルートフォルダー「/」。** アプリ独自の PIN やマスターパスワードはありません。
  紺色のタイトルバー、ツールバー (戻る・上へ・表示切替・新しいフォルダ・新しい鍵・新しいメモ・保存・検索)、その下に「└」で階層を示すパス表示。
- **フォルダー = KeePass のグループ、鍵・メモ = エントリ。** アイコン表示 (5 列) と詳細表示を切り替えられます。
  フォルダーはタップで開く。鍵・メモはタップで選択 (下のプレビュー欄に内容を表示、選択していないときはプレビュー欄なし)、
  選択中の項目をもう一度タップで開く。動かさずに長押しでメニュー。
- **ドラッグで移動 (長押し不要)**: 項目に触れて少し動かすとドラッグになり、フォルダーの上 (中へ)、項目の前後 (並べ替え)、パス表示の行 (上の階層へ) で離します。
  一覧のスクロールは、項目のない所か右端のスクロールバーの帯 (常に表示) をなぞります。端に近づけると自動スクロール。
  並び順はグループの CustomData `KPExplorer.Order` に保存。
- **新しいフォルダ／新しいメモ** は「新しいフォルダ」「新しいフォルダ2」… の名前ですぐ作成。メモはタイトルと本文だけで、
  本文には各行のベースラインに合わせた罫線 (折り返し対応・画面の下まで・文字と一緒にスクロール)。
- **鍵の画面**: ← とタイトル、パス、`Last Modified: YYYY/MM/DD HH:mm:ss`、そして `Title: [入力]` のように 1 行ずつの欄
  (Title / User / Pass / URL / Tag / OTP / カスタム欄)、Memo だけは複数行。いちばん下にも「戻る」「保存」。
  パスワードは最初から表示。「≡」から カスタム欄の追加、欄の表示・並べ替え・削除 (Title 以外はすべて削除可、`KPExplorer.Fields`)、
  消した欄を戻す、パスワードの生成、TOTP (RFC 6238、KeePassXC 互換の `otp` 欄)。未保存の変更があるときは戻る前に確認します。
- **タグ**: スペース区切りで入力 (KDBX の Tags)。入力欄の下に過去に使ったタグのボタンが並び、タップで追加／削除。
  検索では `#タグ` で完全一致、検索ダイアログにも使用済みタグのボタン。
- **鍵の仕組み**: 初回にランダムな 32 バイトの鍵を作り、Android キーストアの AES-256-GCM 鍵 (画面ロックの認証が毎回必要、
  BIOMETRIC_STRONG または端末の資格情報) で包んで保存します。データベースはアプリ専用領域に 1 つ。
  **注意: 端末の画面ロックを解除・無効にするとキーストアの鍵が消え、アプリ内のデータとアプリ内保存のファイルは開けなくなります。**
  大事なデータは「外部に書き出す」で残してください。
- **保存 (ツールバー)**:
  - アプリ内に保存: アプリの中に `backups/2026-11-05.kdbx` (同じ日は `_2`, `_3`…)。「保存したファイルの一覧」から復元・削除・書き出し。
  - 外部に書き出す: 保存先を選び (SAF)、そのとき入力したパスワードで暗号化した普通の KDBX 4 (AES-256 / Argon2id) を書き出します。
    KeePass / KeePassXC で開けます。外部のファイルを開く機能は今はありません。
  - フォルダー操作は変更のたびに自動保存、鍵とメモは画面の「保存」で保存 (読み直して検証し、一時ファイル → rename で置き換え)。
- コピー: 長押しメニューでユーザー名／パスワードをコピー (パスワードは「機密」扱い、45 秒後に消去)。
- 権限はなし (INTERNET なし)。USE_BIOMETRIC のみ。Android 11 以上。

KeePass / KeePassXC / Keepass2Android と同じ KDBX 3.1 / 4 を読み書きします (保存したファイルは `keepassxc-cli` で確認済み)。

## ビルド

JDK 17、Android SDK (platform 35, build-tools 35.0.0)。

```
./gradlew testDebugUnitTest lintRelease assembleRelease
```

リリース署名はリポジトリの外のプロパティファイル (`ZML_KEYSTORE_PROPS`、既定 `/workspace/android/keys/keystore.properties`) から。
無ければ未署名の APK になります。

テスト: KDBX の往復・移動・並べ替え・削除・タグ (`TreeTest`)、並び順・カスタム欄・OTP 欄 (`OrderTest`)、RFC 6238 のテストベクトル (`TotpTest`)、バックアップ名 (`StoreTest`)、画面の描画と操作・書き出したファイルがパスワードで開けること (`UiScreenshotsTest`, Robolectric;
画像は `KPX_SCREENS_DIR` に出力)。手元の .kdbx で試す場合は `KCK_KDBX_FIXTURES` に properties ファイルを指定 (`FixturesTest`; リポジトリには入れない)。
`CompatSampleTest` は `app/build/compat/kpx-sample.kdbx` (パスワード `kpx-sample`) を書き出すので、他の KeePass 実装で開いて確認できます。

## セキュリティ (0.3.3〜)

- データ (`db.kdbx`) は標準の KDBX 4 で、**マスターパスワード** (Argon2id) で暗号化されます。KeePass / KeePassXC でもそのまま開けます。
- 初回セットアップでマスターパスワードを 2 回入力します。パスワード自体は保存しません。
- パスワードから作った 32 バイトの鍵は、認証必須の Android Keystore (AES-GCM) 鍵で包んで `wrapped.bin` に保存し、普段は指紋・画面ロックで開きます。
- 画面ロックの変更などで Keystore の鍵が無効になったときは、マスターパスワードで開くと自動で包み直します。ロック画面には常に「マスターパスワードで開く...」があります。
- メニュー「マスターパスワードの変更...」で変更できます。
- 外部に書き出すときは「今のマスターパスワードと同じ」か「別のパスワード」(2 回入力) を選べます。
- 保存は最後の変更から約 1.5 秒後にまとめて行い、アプリを離れる・ロック・書き出しの前にも保存します。保存時は KDF の salt を保持して導出結果をメモリ上でのみ再利用し (ロック時に破棄)、毎回の Argon2 計算を避けます。マスターシードと IV は毎回新しくなります。
- 履歴 (History) は KeePass 標準どおり `db.kdbx` 内の各エントリーに保存され、1 エントリーあたり最大 10 件です。

### 同梱 kotpass への変更
`BaseKdfProvider` を public にし、エンコード時に KDF の salt/パラメーターを保持する `keepKdfSalt` オプションを追加しています (MIT ライセンスのまま)。
